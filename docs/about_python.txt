Python 是一门广泛使用的高级编程语言，由 Guido van Rossum 于 1991 年发布。
Python 强调代码可读性，语法简洁，支持多种编程范式，包括面向对象、命令式、函数式编程。

Python 拥有庞大的标准库，涵盖文件 I/O、网络、正则表达式、数学计算等模块，
因此常被称为"内置电池齐全"（batteries included）的语言。

Python 在数据科学、机器学习、Web 开发、自动化脚本等领域应用广泛。
NumPy、pandas、PyTorch 等第三方生态使其成为人工智能领域最流行的语言之一。

Python 是解释型语言，代码通常逐行执行；同时也可被编译为字节码以提升运行效率。
Python 3 是当前主流版本，与早期的 Python 2 存在不兼容的语法差异。
